# Боксерский клуб 13

Одностраничный сайт боксерского клуба в Ростове-на-Дону.

## Структура

- `dist/index.html` — разметка сайта
- `dist/styles.css` — дизайн и адаптивные стили
- `dist/app.js` — навигация, фильтры, FAQ и форма записи

## Локальный запуск

Откройте `dist/index.html` в браузере или запустите локальный HTTP-сервер:

```bash
python -m http.server 4173 --directory dist
```

Публикация на GitHub Pages выполняется автоматически после каждого push в ветку `main`.
